# تصور وخطة نظام افتتاحية أنمي سينمائية لـ Roblox

## التصور الإبداعي: «نداء الفجر — Echoes of Dawn»
تبدأ التجربة بسواد هادئ وصوت ريح خفيف، ثم يظهر خط ضوء رفيع كأنه يشق الشاشة. ننتقل إلى لقطة واسعة للعالم عند الفجر، مع ضباب طبقي وتدرج لوني بارد، ثم تتحرك الكاميرا في مسار سينمائي نحو شخصية اللاعب الحقيقية. تتتابع لقطات قريبة قصيرة لتفاصيل الشخصية والعالم، تتخللها ومضات ضوء محسوبة وانتقال ضبابي ناعم. في الذروة تظهر هالة ضوء وجزيئات قليلة حول الشخصية، ثم يدخل عنوان اللعبة بخط واضح وحركة متزنة، يليه سطر ترحيب وواجهة تخطٍ أنيقة. ينتهي المشهد بتلاشي اللون والمؤثرات وتسليم الكاميرا والتحكم للاعب بسلاسة.

التصميم يعتمد هوية أنمي راقية لا تعتمد على مؤثرات عشوائية: ألوان كحلي/بنفسجي مع لمسات ذهبية أو سماوية، تباين واضح، نصوص مختصرة، ومزامنة المؤثرات مع نقاط موسيقية. مدة افتراضية مقترحة 18–24 ثانية، مع زر تخطٍ ظاهر دائمًا وإمكانية تخطٍ بلوحة المفاتيح/اللمس.

## تسلسل المشاهد المقترح
1. **افتتاح — 0 إلى 3 ثوانٍ:** شاشة داكنة، تلاشي تدريجي، صوت أجواء، ظهور خيط ضوء وعنوان تمهيدي صغير.
2. **تأسيس العالم — 3 إلى 7 ثوانٍ:** لقطة واسعة للمكان عبر نقاط كاميرا قابلة للتخصيص، تحريك ناعم للكاميرا، ضباب/تصحيح ألوان خفيفان.
3. **دخول البطل — 7 إلى 12 ثانية:** انتقال إلى الشخصية الفعلية، دوران/اقتراب كاميرا محدود، إبراز بصري خفيف دون تغيير الشخصية أو تعطيلها بشكل دائم.
4. **الذروة — 12 إلى 17 ثانية:** ومضة قصيرة موقوتة، اهتزاز طفيف قابل للضبط، جزيئات أو توهج اختياري، انتقال لوني/ضبابي إلى اللقطة النهائية.
5. **العنوان والتسليم — 17 إلى 22 ثانية:** دخول عنوان اللعبة والنص الترحيبي، إتاحة التخطي طوال المشهد، ثم إزالة الواجهات والمؤثرات وإعادة إعدادات الكاميرا والتحكم كما كانت.

كل توقيت، نص، لون، صوت، نقطة كاميرا، وشدة مؤثر سيكون قابلًا للتعديل من إعدادات مركزية. تُعامل مواقع الكاميرا والأصوات كإعدادات يحتاج صاحب اللعبة إلى تحديدها/إضافة أصولها؛ لن أضمّن أرقام أصول غير متحقق منها أو أصولًا بحقوق غير واضحة.

## المعمارية المقترحة
- **عميل اللاعب (LocalScript):** يبدأ الافتتاح مرة واحدة لكل جلسة، يدير الكاميرا وواجهة المستخدم والإدخال والمؤثرات المحلية، ويحفظ الإعدادات الأصلية ويعيدها عند الإنهاء أو التخطي أو الخطأ.
- **وحدة إعدادات (ModuleScript):** تسلسل المشاهد، النصوص، الألوان، المدد، إعدادات الحركة، ومعرّفات الأصول التي يملؤها المطور.
- **وحدة مشاهد/كاميرا (ModuleScript):** إنشاء مسارات الكاميرا والتنعيم والانتقالات، مع دعم لقطات الشخصية ونقاط كاميرا العالم.
- **وحدة واجهة ومؤثرات (ModuleScript):** واجهة متجاوبة، زر تخطٍ، Fade/Blur/Flash/Zoom، وتنظيف العناصر والاتصالات.
- **تهيئة خادمية اختيارية:** لا تُستخدم إلا إذا احتاجت اللعبة علمًا مشتركًا أو تنسيقًا خادميًا؛ التشغيل والمؤثرات البصرية محلية لتقليل الحمل وعدم منح العميل صلاحيات لعب غير لازمة.
- **إدارة آمنة للموارد:** إنهاء موحد idempotent، إلغاء الـTweens، فصل الاتصالات، إزالة المؤثرات والأصوات، والتعامل مع إعادة ظهور الشخصية أو مغادرة اللاعب أثناء المشهد.

## مراحل التطوير بعد موافقتك
1. **تثبيت بيئة التسليم:** فحص الملفات المتاحة وتحديد صيغة المصدر المناسبة لـ Roblox Studio (ملفات Luau منظمة، أو مشروع قابل للاستيراد إذا توفرت الأدوات المناسبة)، وتوثيق المتطلبات والأصول التي يلزمك تزويدها.
2. **بناء الأساس والإعدادات:** إنشاء الإعدادات المركزية ووحدات العميل، وتعريف واجهة بدء/إيقاف آمنة وسهلة التخصيص.
3. **تنفيذ الكاميرا وتسلسل المشاهد:** كاميرا Scriptable مؤقتة، لقطات قابلة للتكوين، Tweening، Zoom/Pan، اهتزاز محدود، وإظهار الشخصية عند توفرها.
4. **تنفيذ الواجهة والانتقالات:** واجهة أنمي متجاوبة، نصوص متحركة، التخطي، Fade/Blur/Flash/Color transitions، ودعم الإدخال للموبايل والحاسوب.
5. **الصوت والمؤثرات:** نقاط مزامنة للصوت، إعدادات مؤثرات خفيفة اختيارية، وضوابط جودة لتقليل الحمل؛ لا تُستخدم أصول خارجية إلا بعد التحقق من المصدر والترخيص/التوافق أو تزويدك بمعرّفاتها.
6. **التكامل والمراجعة:** مراجعة مسارات التنظيف والاستعادة، حالات الخطأ وإعادة الظهور، توثيق README وخطوات وضع الملفات في Roblox Studio، وفحص ما يمكن فحصه في بيئة المشروع.
7. **التسليم وGitHub:** فحص وجود صلاحية GitHub أو مستودع مرتبط قبل الادعاء بالرفع. إن لم تتوفر المصادقة/الربط أو لم تكن أدوات المشروع مناسبة لإنشاء مستودع، أسلّم المصدر المنظم والوثائق وأوضح بدقة ما يلزم لإتمام النشر؛ لن أرفع أو أدّعي رفعًا دون نجاح فعلي.

## الاختبار ومعايير القبول
- التشغيل مرة واحدة وعدم تكرار الافتتاح بلا قصد.
- التخطي يعمل باللمس والماوس/لوحة المفاتيح، ولا يترك حالة كاميرا أو تحكم عالقة.
- استعادة نوع الكاميرا وهدفها وخصائصها، وإزالة الـBlur/ColorCorrection والواجهة والأصوات بعد النهاية.
- احتواء حالات غياب الشخصية أو إعادة ظهورها أو انقطاع التنفيذ على إنهاء آمن.
- التحقق من وضوح الواجهة على الشاشات الصغيرة والكبيرة، ومن خفة عدد المؤثرات والاتصالات.
- ملاحظة: بيئة Roblox Studio غير ظاهرة ضمن الملفات الحالية، لذلك اختبار Luau داخل اللعبة يتطلب تشغيل السكربتات في Studio؛ سأفصل هذا عن أي فحص يمكن إجراؤه هنا.

## افتراضات وحدود واضحة
- الاسم «Echoes of Dawn» والأسلوب البصري تصور أولي ويمكن تغييره قبل التنفيذ.
- لا أفترض توافر أدوات Scout/Vision/Architect/Forge/Titan/Sentinel أو أن أي وكيل نفّذ عملًا؛ لا تظهر لي أدوات تنسيق وكلاء في هذه الجلسة.
- لا أضع أصولًا مدفوعة/مجهولة الترخيص ولا أختلق روابط أو معرّفات أصول. يمكن إدخال أصولك لاحقًا عبر الإعدادات.
- أبدأ كتابة الملفات فقط بعد موافقتك على التصور والخطة.
